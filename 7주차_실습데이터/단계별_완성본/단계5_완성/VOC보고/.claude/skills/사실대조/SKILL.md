# 사실 대조

보고서를 만든 대화가 아닌 **새 대화**에서 실행한다. 사람에게 묻지 않고 아래 규칙대로 끝까지 진행한다.

## 순서
1. **대상과 기준 월**
   - 기준 월: 요청에 적힌 달 → 없으면 요청한 파일 이름의 YYYY-MM → 그것도 없으면 실행한 날의 지난달
   - 대상: 요청에 파일이 있으면 그 파일, 없으면 `산출/최신/보고서구성안_{기준 월}.md`
   - 요청에 파일이 없을 때: 구성안이나 `VOC보고_{기준 월}.pptx`가 없으면 "보고서 없음", `산출/최신/사실대조_{기준 월}.md`가 이미 있고 "다시 대조해 줘"라는 요청이 아니면 "이미 대조함"이라고 알리고 멈춘다
   - 요청에 파일이나 저장 이름이 있을 때: 위의 두 멈춤 검사를 하지 않고 그 파일을 대조한다
2. **근거** — 아래만 읽는다. 웹을 검색하지 않는다.
   - 수치: `산출/최신/집계_{기준 월}.json`
   - 접수번호·접수 내용: `산출/최신/정리본_{기준 월}.xlsx`
   - 사례: `데이터/조사/{기준 월}/`의 자료 파일
   - 지난달 과제 점검: `기억/진행상태.md`
3. **대조** — 구성안의 수치·날짜·인용·접수번호·기관과 기업 이름을 한 줄씩 근거와 대조해 표를 만든다.
   표: 구성안 문장 | 확인한 값 | 근거 | 판정(일치 / 불일치 / 근거 없음)
4. **고치기** — 사람에게 묻지 않고 아래 규칙대로 고친다. 요청에 "고치지 말고"가 있으면 이 단계와 5번의 보고서 재생성은 하지 않는다.
   - 불일치 → 근거의 값으로 고친다
   - 근거 없음 → 그 문장을 지운다
5. **저장** — 표와 고친 내역을 `산출/최신/사실대조_{기준 월}.md`에 저장한다. 요청에 다른 파일 이름이 있으면 그 이름으로 저장한다.
   고친 줄이 있으면 구성안과 보고서를 `산출/백업/`으로 옮긴 뒤, 고친 구성안을 저장하고 `VOC월간보고` Skill 8번과 같은 방법(디자인 설정, 표시 제외, 구성안에 없는 문장 제외)으로 `/pptx-deck:create-deck`을 써서 보고서를 다시 만든다.
6. **기록** — `기억/실행로그.md`에 한 줄 덧붙인다 (작업: 사실대조, 불일치·근거 없음 건수).

## 하지 말 것
- 근거 밖의 자료를 찾지 않는다
- 일치인 줄은 고치지 않는다
- `기억/진행상태.md`를 바꾸지 않는다
