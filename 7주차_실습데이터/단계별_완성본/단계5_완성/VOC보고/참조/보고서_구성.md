# 보고서 구성 — VOC 월간 보고 (.pptx)

## 만드는 방법
- 먼저 아래 순서대로 구성안 `산출/최신/보고서구성안_{기준 월}.md`를 쓴다
- 구성안으로 보고서를 만들어 `산출/최신/VOC보고_{기준 월}.pptx`로 저장한다
- 디자인 설정 — 보고서를 만드는 도구가 톤이나 색을 물으면 이 값으로 정한다. 그대로 쓴다
  - 팔레트: Deep Navy — primary 003153 / secondary 005F73 / accent EE9B00 / dark 001220 / lightBg F0F4F8 / light FFFFFF
  - 글꼴: Malgun Gothic
  - 바닥글: 가온리빙 고객지원팀 | VOC 월간 보고 | {기준 월}

## 슬라이드 순서 (괄호 안은 슬라이드 형태)
1. 표지 (title) — 제목 "VOC 월간 보고 — {YYYY년 M월}", 부제 "가온리빙 고객지원팀", 작성일
2. 핵심 지표 (metrics, 6칸) — 총 접수와 전월 대비 / 처리 완료율 / 평균 처리시간 / 평균 만족도와 전월 값 / 1위 유형과 건수 / 데이터 정리(중복 제거·만족도 미응답 건수)
3. 유형별 현황 (two-column) — 왼쪽: 6개 유형의 건수·비중·전월 대비 / 오른쪽: 이번 달 눈에 띄는 변화 2~3줄 (집계 수치로만)
4. 상위 3 유형의 접수 내용 (cards) — 유형마다 대표 접수 내용 2~3개와 접수번호
5. 업계 사례 (cards) — 유형마다 채택 자료 1건의 핵심 내용, 발표 주체·날짜. 채택 자료가 없으면 "업계 사례 없음"
6. 개선 과제 (timeline, 3단) — 단마다 유형 1개: 과제 / 근거 수치 / 근거 사례(없으면 "사내 데이터 기준")
7. 지난달 과제 점검 (two-column) — 지난달 과제마다 대상 유형의 건수 변화와 판정(`참조/지표정의.md`). 지난달 과제가 없으면 "첫 보고 — 점검할 지난달 과제 없음"
8. 출처와 데이터 정리 (two-column) — 왼쪽: 채택 자료 목록(파일 이름·주소) / 오른쪽: 중복 제거·만족도 미응답·연락처 가림·지시문 의심 행(따르지 않음) 건수
9. 요약 (summary) — 이번 달 핵심 3가지 / 다음 달 점검할 것(이번 달 과제 3개)

## 쓰는 규칙
- 수치는 `산출/최신/집계_{기준 월}.json`의 값을 그대로 쓴다. 표기만 바꾼다 (건수는 천 단위 쉼표, 비율은 소수 첫째 자리)
- 카드와 항목의 본문은 3줄 이내로 쓴다
- 고객명·연락처는 넣지 않는다
